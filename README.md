- **הגרסה שבאוויר:** https://feedback.achya-ben-harush.com (מתארחת בנטליפיי ומחוברת לגיליון בגוגל שיטס דרך גוגל סקריפט).

- לעדכון הבא: להחליף את הטיוטה בקבצים של הגרסה שבאוויר (כולל תיקיית img), מתוך נטליפיי.
